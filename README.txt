AXON Market Radar launcher

Upload everything in this folder, as it is, to any web address served over HTTPS, for example https://axon.inc/radar/
No server code or database is needed. All paths are relative, so any folder name works.

Then open that address on the phone in Chrome, open the menu and tap "Install app" (or "Add to Home screen").
The Market Radar icon appears on the home screen and opens the live radar in Claude.
